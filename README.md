# 信流 · 读懂一天

中外资讯，加一座城市。时政、AI、社会热点与艺术，从消息读到背景；城市介绍，从街巷走向山海。

网站：[信流](https://wyw2608.github.io/xinliu/) · 源码：[wyw2608/xinliu](https://github.com/wyw2608/xinliu)

## 当前内容与功能

- 2026年11月1日：8篇中外新闻、1篇京都城市介绍，25项原始资料与2张授权实景照片；本期正文约16分钟，页面显示实际估算。
- “选择日期”按钮可以打开2026年10月30日、31日及11月1日的简报，日期也可通过网址 `?date=2026-10-30` 分享。仅展示已出版的日子，不生成空白或未来简报。
- 五个栏目可独立筛选，支持搜索、只看未读、本期收藏、字号与深色模式。
- 阅读进度与收藏按日期保存，浏览器返回/前进也会切换简报；旧版阅读记录迁移保留。
- 正文简洁连贯，文中注号打开文末资料；图片随图保留作者、来源、许可与年代。
- 配图在同一网站托管；无广告、统计SDK、第三方字体或脚本。收藏与进度仅存在当前浏览器。
- **当前按需更新，用户已明确暂不启用自动日更。没有后台定时任务。**

内容由AI检索一手资料后原创综合，不搬运媒体新闻成稿。资料日期、检索记录和证据范围见 [11月1日编辑记录](docs/2026-11-01-检索与图片记录.md)、[10月31日编辑记录](docs/2026-10-31-检索与图片记录.md)、[10月30日编辑记录](docs/本期检索与编辑记录.md)与[内容生成准则](EDITORIAL.md)。

## 本地运行

Node.js 22+，无第三方依赖。

```sh
npm test
npm start
```

在浏览器打开 `http://127.0.0.1:5173`；预览服务仅监听本机。

## 数据与部署

- `dist/index.html`、`app.js`、`core.js`、`style.css`：静态阅读器。
- `dist/editions/index.json`：已出版日期目录，`latest` 指向最新一期。
- `dist/editions/YYYY-MM-DD.json`：按日期保留正文、原始来源与图片署名。
- `dist/assets/`：授权照片与许可记录。
- `dist/edition.js`：最新一期兼容导出，供校验使用；阅读器按日期加载JSON。
- `tests/`：内容完整性、日期范围、跨期存储及安全外链检查。

新增一期时保留旧日期文件，更新日期目录和最新兼容导出；修订同一期时递增目录中的 `version`。页面资源也使用版本标记，避免混用旧缓存。

GitHub Pages从main分支根目录发布，根入口跳转到dist/。无构建依赖、数据库、浏览器API密钥或常驻服务器。Sites副本复用 `.openai/hosting.json` 的项目与现有私有访问权限。

图片压缩文件是磁盘存储；浏览器显示时会解码到运行内存。Git仓库保留版本历史，删除当前文件不会自动清除旧版本。项目大小、进程内存与发布文件大小需要分开衡量。
