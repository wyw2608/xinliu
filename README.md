# 信流 · 读懂一天

一份有边界的每日简报：时政、AI、社会热点与艺术。读懂一天，然后回到生活。

**当前为检索一手资料后原创整理的网页版简报，已停止鸿蒙端开发。** 原生工程不属于这个仓库。

## 已有功能

- 适配手机和桌面的四栏目阅读界面，栏目筛选、关键词搜索、只看未读。
- 文章阅读窗口：事实与背景、争议说明、尚不确定、来源与原文。
- 已读进度、收藏、字号、浅色/深色模式；仅保存在当前浏览器。
- 本地数据清除；键盘操作、原生对话框、减少动画偏好支持。
- 无广告、无统计SDK、无账号、无第三方字体或脚本。

本期（2026-10-30）已用真实网络资料替换虚构演示，共8篇、19项一手资料，中国与国际各4篇。正文由AI原创综合，逐段关联原始来源，区分发布方主张、信流分析和未知；没有搬运媒体新闻成稿。阅读量约17分钟，长期目标约20分钟。

本期未进行独立采访或人工新闻编辑复核。部分材料是近期报告或背景，均标明日期。当前按用户触发更新，**未开启每天自动生成或推送**。

详见[内容生成准则](EDITORIAL.md)和[本期检索记录](docs/本期检索与编辑记录.md)。

- Sites 部署使用 `.openai/hosting.json` 所绑定的项目；访问权限以该站实际设置为准。

## 本地运行

需要 Node.js 22+。没有第三方依赖，无需安装额外包。

```sh
npm test
npm start
```

在浏览器打开 `http://127.0.0.1:5173`。开发服务器仅监听本机。ES Module需要通过HTTP访问，不建议直接双击HTML文件。

## 项目结构

```text
dist/                 可直接托管的静态网站
  index.html          阅读器与对话框
  style.css           响应式样式与主题
  app.js              页面交互
  core.js             筛选、时长、存储与外链处理
  edition.js          原创简报、来源和检索记录
  favicon.svg         信流标识
docs/                 网页版实施计划与来源授权调研
tests/                关键逻辑测试
preview.mjs           本地预览服务
index.html            GitHub Pages根入口
```

## 更新与部署

修改 `dist/` 内源码即可。GitHub Pages 采用 `main` 分支根目录发布；根目录入口跳转到 `./dist/`，所有资源均使用相对路径，适配仓库子路径。`.nojekyll` 用于直接发布静态资源。无构建步骤，也没有在浏览器暴露新闻API密钥。

Sites 发布遵循其项目ID、源代码同步和保存版本流程。仅上传网站静态资源，不把后端密钥、合同或私人数据加入公开仓库。

后续真实日报需要服务器、人工编辑、内容授权与发布条件，详见[实施方案](docs/实施方案.md)和[来源与授权调研](docs/来源与授权调研.md)。不得用改日期的方式把旧资料当作今日消息。
