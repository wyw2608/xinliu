# 信流：来源与授权调研

核实日期：2026-10-30（Asia/Shanghai）。产品现已调整为网页版，已停止鸿蒙端开发。以下保留新闻来源、版权与运营要求的调研。

## 新闻来源/API对比

| 方案 | 当前公开信息 | 授权边界与建议 |
|---|---|---|
| NewsAPI | Developer免费，100请求/日、24小时延迟；Business按月$449。免费开发计划不允许正式/预发布环境，包括内部正式使用 | 免费版不适合“当天实时简报”。服务不提供完整正文；将其视为发现线索工具，另核实发布者权利 |
| GNews | Free为非商业开发/测试等用途，100请求/日、12小时延迟；Essential按月€49.99，1000请求/日、实时文章、提供正文 | 付费满足商业API使用条件，但条款明确不授予第三方新闻的版权；展示、摘要和离线仍需核实 |
| Guardian Open Platform | Developer为非商业用途，最高1请求/秒、500请求/日、可访问文章文本；商业用途需申请按用量定价的Commercial key | 来源身份和商业联系路径清楚，但只有一个媒体视角，不能单独覆盖编辑平衡；摘要、翻译、缓存等按适用合同核查 |
| AP Media API | 提供合同范围内的已授权文字、图片、视频等内容；公开资料为定制授权，未见统一自助价格 | 更适合有预算的正式内容合作；明确中文翻译、地区、客户端和衍生摘要权限 |
| 国内权利人直接授权 | 例如新华网版权声明要求使用其作品前获授权，按授权范围使用并署名；没有据此确认一个公开免费通用API | 大陆新闻产品优先谈清实际权利链与运营资质。网页可访问或有RSS不构成默认转载许可 |
| 一手材料/专题来源 | 政策原文、论文、厂商发布、展馆公告有助于核实事实 | 逐站、逐作品检查适用许可；厂商说法应标成厂商宣称；素材许可与新闻运营许可分开核实 |

对应一手来源：

- NewsAPI：[价格](https://newsapi.org/pricing)、[条款](https://newsapi.org/terms)、[正文可用性说明](https://newsapi.org/docs/guides/how-to-get-the-full-content-for-a-news-article)。官方文档提及如何另外取得正文，不代表本项目获得抓取或转载权。
- GNews：[价格](https://gnews.io/pricing)、[2026-10-18版条款](https://gnews.io/legal/terms-of-service)。重点看3.3（商业/API数据）、5.2和6.2（第三方内容）、7（禁止大规模建立竞争性数据库）、8.4（终止后处置）。普通付费订阅结束后的已取数据规则与违规终止不同；即便允许保留API数据，也仍受第三方版权限制。
- Guardian：[访问层级](https://open-platform.theguardian.com/access/)。签约时另审查完整条件，不能仅凭“免费开发Key”推断付费产品可用。
- AP：[API概述](https://developer.ap.org/ap-media-api/agent/Overview.htm)、[定制授权](https://www.ap.org/content/subscriptions/)。API可取得哪些内容取决于合同。
- 国内权利人示例：[新华网版权声明](https://www.xinhuanet.com/copyrightad.htm)。转载在该站的第三方内容不一定由该站拥有完整再授权权利。

**建议：本地演示用原创说明 → 明确运营主体 → 谈少量直接授权 → 接入编辑后台 → 再用聚合API扩大线索发现。** 这是结合本产品定位的实施建议，不是服务商保证你已获得许可。两家聚合器都返回同一篇文章，也不会因此形成两个独立消息源。

## 公开发行相关原文

| 原文 | 与项目直接相关的点 |
|---|---|
| [《互联网新闻信息服务管理规定》](https://www.cac.gov.cn/2017-05/02/c_1120902760.htm) | 第2条定义包含公共事务及社会突发事件的报道、评论；第5条要求相应许可；第15条规定转载来源、署名及著作权要求 |
| [《移动互联网应用程序信息服务管理规定》](https://www.cac.gov.cn/2022-06/14/c_1656821626455324.htm) | 第7条再次要求APP提供新闻信息服务（网站另按对应规定核实）取得许可；不能把“手机端”理解为例外 |
| [工信部APP备案通知](https://www.miit.gov.cn/zwgk/zcwj/wjfb/tz/art/2023/art_920db564162e4312916a01bed6540ad8.html) | 在境内从事相关服务需履行备案；新闻等服务还须提交有关主管部门审核同意文件；需展示备案编号 |
| [《个人信息保护法》](https://www.cac.gov.cn/2021-08/20/c_1631050028355286.htm) | 第6条要求目的明确、范围最小，第7条要求处理规则透明 | 
| [《人工智能生成合成内容标识办法》](https://www.cac.gov.cn/2025-03/14/c_1743654684782215.htm) | 自2025-09-01实施，涉及显式/隐式标识及传播服务相关责任；应根据实际AI生成与传播功能落实 | 

公开运营的具体服务类别、主体资格和申请材料，仍需结合项目实际向主管部门和分发平台核实。这也是为什么本项目默认用明确标识的演示内容，而没有接入未经授权的新闻列表。
